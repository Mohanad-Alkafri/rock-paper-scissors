# rock-paper-scissors
rock paper scissors project for the odin project curriculum.
in this project i will try and practice most of the skills and info i have obtained throughout the curriclem.
i learnt somehow a different method of using git by first `git init` and then `git add .`, `git commit --m "comment"`, `git branch -M main` to choose the branch we are storing on, and then `git remote push -u origin main` to push everything to the main branch on my github repository.  
line 4 is only for initializing the repo but after that you just commit and push.
